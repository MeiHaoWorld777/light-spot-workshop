# 光斑小工坊

瑞吉欧教育基调的儿童光影互动小游戏。清晨的阳光从左侧窗户漫进一间安静的手工教室，
孩子在原木桌面的光束里摆放镂空纸片、彩色胶片与小积木，墙面的"光影投影区"会随之
浮现大小不一的影子与低饱和的彩色光斑。

- 玩法适配 3 岁左右儿童：全程无文字操作提示、无失败反馈，所有动效统一"偏慢"档。
- 技术形态：纯静态网页（Three.js r161 本地化引用，无任何构建与外部 CDN 依赖）。

## 运行

任意静态服务器指向本目录即可，例如：

```bash
cd light-spot-workshop
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

也可以直接使用 ZCode 的 deploy_website 工具部署。

## 玩法与功能

**瑞吉欧拓展玩法（v2）**

| 模块 | 说明 |
| --- | --- |
| 可拖动的太阳 | 透过窗户抓住太阳沿弧线拖动：高度改变光的角度，影子随之变长变短、方向偏移，色温从正午暖白到地平线金橙；也是给孩子的"光的科学"第一课 |
| 手绘剪影 | 托盘中间的魔法画纸，点一下进入涂鸦画板（4 色粗蜡笔、无文字），按 ✓ 后画作化作桌上实体纸片，墙上影子就是孩子画的形状——孩子从玩家变成作者 |
| 影子剧场 | 拉一下后墙的绳子，白色幕布落下、房间灯光转暗，所有影子投在幕布上；再拉收幕时——如果孩子在幕布期间"演出"过——物件会自动重演一遍刚才的轨迹，最后全体"谢幕鞠躬"后才收幕亮灯 |
| 照片钉上墙 | 相机拍摄的作品会"飞"到墙上的软木展示板（3×3 位，持久保存），孩子在环境里看见自己作品的积累 |
| 窗户玻璃纸 | 把彩色胶片拖到窗玻璃上"贴"住，全屋光线染成该颜色；多张叠加按光学混色；再点一下取下来 |
| 一碗水 | 桌上的水碗在墙面投出缓缓晃动的粼粼波光（程序化焦散）；点一下碗会泛起涟漪、波光闪动并响起水滴声；云朵遮光时波光变暗，窗户贴了玻璃纸时波光会染上那个颜色 |
| 会呼吸的房间 | 窗台绿植的影子随风摇曳；窗外偶尔有小鸟飞过 |
| 手影游戏 | 手掌纸片放进靠窗的"魔法角"，墙上的手影会慢慢变身：兔子→飞鸟→小狗，循环往复——把传统手影游戏搬进光影教室 |
| 编织材料篮 | 桌角的编织篮，点一下"倒"出一张新纸片（星星→小鱼→手掌），轮换出现 |
| 新纸片形状 | 星星（镂空圆心）、小鱼（镂空眼睛与鳃缝）、纸片小人加入可剪、可投影的纸片家族 |
| 手电筒与双影 | 右墙搁架取下手电筒放到桌面：附近的纸片会投出第二道方向不同的影子——两盏光源两个影子，月夜里它还是主光源；轻点手电筒可开关 |
| 旋转剪影筒 | 镂空着星星月亮的剪影筒放进光束，墙上的光带里星月图案缓缓流动 |
| 孩子视角 | 右上角"小人"图标：相机降到三岁孩子的眼睛高度，抬头看墙上的影子如巨影环绕 |
| 梦境存档 | 整个场景（纸片位置、孩子的画、玻璃纸、太阳高度、云朵）每 4 秒静默保存，下次打开一切如原样——工作坊跨天延续 |
| 一键重置 | 右上角圆形回旋箭头按钮，点一下所有东西放回原位、天色恢复、场景清空重来（梦境存档同步清空） |
| 涂鸦撤销 | 画板上按一下 ✕ 只拿掉最后一个笔画/形状（按钮轻轻缩一下示意），长按才是清空全部——孩子画错不再前功尽弃 |
| 离线安装 | PWA：支持"添加到主屏幕"离线游玩，适配机构平板批量部署 |
| 月夜模式 | 连续游玩到太阳完全落山后，月亮从窗外升起、星空浮现、影子变成清冷的淡蓝灰、虫鸣替代鸟鸣，萤火虫会自己来做客；家长设置"恢复白天"即可 |
| 棱镜与彩虹 | 托盘里的水晶三棱镜放进光束，白光会散开一道低饱和彩虹带；若窗户贴了玻璃纸，色光无法分散，墙上只剩一条对应颜色的单色亮带——色散跟随入射光真实变化，棱镜本身还有玻璃高光闪点 |
| 羽毛 | 托盘里的一根羽毛：影子边缘绒毛般柔软，飘落时慢慢摇摆、几乎无声 |

| 模块 | 说明 |
| --- | --- |
| 开场动画 | 约 12 秒：暖米白淡入 → 光带从左向右亮起 → 镜头自墙面推向主视角 → 标题浮现停留后淡去；点击任意位置可跳过 |
| 材料凹槽 | 树叶/花瓣镂空纸片、小鸟/小兔剪影纸片、红黄蓝半透明胶片、方块/圆柱积木、剪刀，共 10 格，间距宽松，选中微微上浮 |

| 剪刀 | 拖到纸片上方纸片微微发光，松手后沿中线缓慢分开成两片，墙上影子同步分开（剪刀本体在墙上也是剪刀形剪影），桌面闲置 15 秒自动飘回托盘，随时可再抓起 |
| 拍照 | 右上角极小的相机图标：暖白闪光 + "咔嚓"，作品静默存入 localStorage（最多 20 张），家长设置内可查看/导出/清空 |
| 彩蛋 | 连点墙面光影区 3 次飘过一枚小光斑；小鸟剪影拖到窗边，墙上的影子会扇两下翅膀 |
| 闲置唤醒 | 10 秒无操作，一朵云自己慢慢飘一段 |
| 时长保护 | 默认连续游玩 10 分钟后太阳缓缓落山、画面轻暗（不强制退出）；家长可调 10/20/30 分钟或不限，可"恢复白天" |
| 家长设置 | 右下角时钟图标按住 1.1 秒打开：音效开关、时长、作品相册、恢复白天、重新开始 |
| 声音 | 全程序化 WebAudio 合成：微风白噪音、远处鸟鸣、拖拽风声、纸声/木声/剪纸/快门、开场钢琴单音；落物带五声音阶音高，不同颜色胶片对应不同音（光色声通感） |
| 双孩共玩 | 多点触控：两个孩子可以同时各拖各的（一个管云、一个管纸片） |
| 教师观察页 | 家长面板内附累计观察统计（探索时长/剪纸/绘画/混色/照片）与可导出的《观察报告》txt——机构的"教学记录"素材 |
| 场景精装修 | 木地板条板纹、圆形地毯、窗帘与顶幔、重做的盆栽（叶脉叶片+陶盆）、墙上蜡笔涂鸦小画、书架上的小书、地板小球、窗边风铃（拖云时轻晃轻鸣）、桌面木纹 |
| 增添生活气息 | 后墙三角旗彩旗串（随风轻摇）、地板上打盹的泰迪熊（轻轻呼吸）、小木架上的橡皮小鸭与笔筒、画架旁散落的蜡笔 |
| 防闪烁 | 托盘站立道具缩小收拢 + 交替微扇（几何不再交叠）；梦境恢复逐件分配层高；归位时重新立起——全场景零 z-fighting |
| 家长引导卡 | 家长设置内附开放式提问示例，把家长变成瑞吉欧式的观察者与提问者 |

## 代码结构

```
index.html          页面骨架、覆盖层 DOM 与样式
lib/three.module.js Three.js r161（本地化）
src/
  game.js           主控：装配、主循环、云朵遮光、落山、拍照、调试钩子
  scene.js          场景：房间/窗/桌/天空/光束棱柱/灯光/太阳状态机
  shadows.js        光影系统：风格化投影、三级模糊图集贴花、胶片混色、亮斑与光池
  items.js          道具：纸片/胶片/积木/剪刀/云朵、托盘、抓取动效、剪纸分半
  gameplay.js       交互：拖拽/吸附/剪纸/彩蛋/闲置唤醒/时长保护
  ui.js             开场时间轴、标题、家长设置、闪光、相册
  audio.js          WebAudio 合成音效
  textures.js       Canvas 程序化美术：纸片、镂空、撕纸 Logo、柔贴图
```

## 调参入口

- 光影手感：`src/shadows.js` 顶部 `L`（shear/drop/grow/blur）与 `ZONE`（光束区椭圆）。
- 视角范围：`src/gameplay.js` `onMove` 中 yaw/pitch 的 clamp 值。
- 遮光曲线：`src/game.js` 主循环中 `1 - 0.95 * occl^0.62`。
- 明暗摆动：`src/scene.js` `applySun()` 中的强度与冷暖插值。
- 落山时长：`src/game.js` `triggerDusk()` 的 40 秒渐变。

## 测试钩子

页面暴露 `window.__lsp`：`state()` 返回全部物品/云/光强状态，`screenPos(item)` 返回
屏幕坐标，`skipIntro()` 跳过开场——便于自动化黑盒测试。
